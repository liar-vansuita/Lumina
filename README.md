# Lumina

Aplicativo financeiro PWA inicial.

## Publicar
1. Envie todos os arquivos e pastas deste projeto para a raiz do repositório GitHub.
2. Abra Settings > Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Branch: main | Folder: / (root) e clique Save.
5. Aguarde o endereço publicado.

## Importante
- Receitas, despesas e objetivos são salvos localmente no navegador deste dispositivo.
- Use Exportar dados para fazer backup.
- Sincronização entre dispositivos ainda não está configurada; requer banco de dados/serviço na nuvem.
- Para testar offline, abra o app publicado pelo menos uma vez enquanto estiver online.
